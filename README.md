  # vasp-tools
  处理 VASP 输出文件的小工具集。能够读取结构优化后OUTCAR中包含的离子步数及其能量信息。
  ## 为什么需要它
  计算过后生成的OUTCAR中输出的能量值繁多，需要理清哪些部分是真正离子步所计算出的能量，哪些部分是电子步（也就是中间产物）。
  ## 怎么用
  在包含OUTCAR的文件夹中运行：
  ```
  python read_outcar.py sample_OUTCAR.txt
  ```
  ## 输出
  示例输出如下:
  离子步数: 5
  最终能量: -18092.44087654 eV
  最低能量: -18092.44087654 eV
  最高能量: -18090.2271234 eV
  总共降了: 2.2137531400003354 eV
  ## 环境
  python 3.11 无第三方依赖
